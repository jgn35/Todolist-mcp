- (decision) Intent: Create PRD for Todolist MCP server. User goal: Allow LLMs to manage task lists for individual users. Scope: Personal use initially. Language: French.
- (decision) Core features: CRUD tasks (create, read, update, complete, delete), prioritization, due dates management. Persistence: open source database. Auth: single-user with authentication. Access: MCP only. Success: LLM can query today's tasks, tomorrow's tasks, add tasks from reminders, mark tasks as completed.
- (decision) Stakes calibration: Personal use / hobby project. Form factor: MCP server (Python). Database: SQLite (open source, file-based, perfect for single-user). Auth: Basic token-based for single user.
- (event) PRD initial draft created with essential spine: Vision, Target User, Glossary, Features (CRUD + priority + due dates + auth), Non-Goals, MVP Scope, Success Metrics, Open Questions, Assumptions Index
- (decision) Validated assumptions: LLM can parse user requests, task matching by text similarity is sufficient, single token auth is OK. Decisions: timestamp format = simplified local (YYYY-MM-DD HH:MM:SS), timezone = local machine, token generation = CLI command. User Journeys: 3 UJs confirmed as sufficient.
- (change) Updated PRD: Added FR-13 for CLI token generation. Updated timestamp format to simplified local (YYYY-MM-DD HH:MM:SS). Updated due_date filter to use local timezone. Removed resolved assumptions and open questions.
- (decision) Resolved Open Questions: OQ-1=Generate new ID automatically on conflict, OQ-2=No task limit, OQ-3=No token rotation for v1. Resolved Assumptions: Both §4.1 assumptions validated by user.
- (event) PRD finalized. Status changed to 'final'. All Open Questions and Assumptions resolved. Added implementation details from resolutions: auto ID generation on conflict, no task limit, no token rotation for v1.
